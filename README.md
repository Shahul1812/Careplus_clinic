# CarePlus Clinic — Advanced Multi-Page Demo

A polished fictional healthcare website concept based on the uploaded CarePlus single-page design.

## Pages
- index.html — Home
- services.html — Services
- doctors.html — Specialists
- about.html — About
- appointment.html — Appointment
- contact.html — Contact

## Features
- Responsive multi-page layout
- Scroll reveal animations
- Animated counters
- Hover tilt interactions
- Cursor glow on desktop
- Scroll progress indicator
- Sticky glassmorphism navigation
- Mobile navigation
- FAQ accordion
- Appointment/contact demo forms with validation and toast feedback
- Reduced-motion accessibility support
- External high-quality image references via Unsplash

This is a front-end demo. Appointment submissions are not connected to a real medical scheduling backend.
